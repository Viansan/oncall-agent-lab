# 星桥网关运行手册

这是为本项目编写的虚构运行手册，用于演示请求入口异常的排查流程。

## 典型信号

- 五分钟错误率连续高于 3%。
- 请求响应时间显著高于日常基线。
- 单一版本发布后出现集中失败。

## 立即处置

- 暂停新的版本发布，记录异常开始时间。
- 对比最近一次配置变更与错误率变化。
- 若故障只出现在新版本，将流量切回上一稳定版本。

## 核查步骤

- 运行 `labctl gateway summary` 查看虚构网关的错误分布。
- 运行 `labctl gateway changes --last 30m` 核对最近变更。
- 抽取三个失败请求，确认是入口拒绝还是下游响应慢。

## 升级条件

- 十分钟内错误率没有下降，升级给平台值守负责人。
- 多个下游同时异常时，创建跨服务事件并停止非必要变更。
